API DOCUMENTATION
Tabaarak SMS Gateway API – Professional Developer Documentation
Introduction
The Tabaarak SMS Gateway API is a secure, high-performance platform built for developers and
businesses looking to integrate SMS messaging, contact management, and mobile wallet
payment systems. Designed to be developer-friendly, modular, and scalable, the API simplifies
communication workflows and provides essential tools for digital engagement.
Purpose
To deliver a unified solution for SMS communication, contact group management, and digital
payment processing through a simple, secure API interface.
Target Users
 Software Developers & Integrators
 Government & NGOs
 Educational Institutions
 Telecom Service Providers
 Business Enterprises
Authentication
Endpoint
POST https://sms.tabaarak.com/Auth/SMSLogin
Description
Authenticates users and issues a secure access token for subsequent requests.
Request Body
